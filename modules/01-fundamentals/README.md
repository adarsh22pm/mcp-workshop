## 📚 What You'll Learn

2. **Why do agents need MCP?** — How Claude, ChatGPT, and Cursor discover and use tools
3. **How agents pick tools** — Why description and naming matter more than you think
4. **Real examples** — Agent workflows that work, and ones that fail

## 💡 Key Takeaways

- MCP is how AI agents access your product
- Agents discover tools by reading descriptions and names
- A 2-line description can make or break whether an agent uses your tool
- You're writing UX for agents, not humans
